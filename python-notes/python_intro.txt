Variable Naming Rules :
            => These rules are important when creating variables.

            Rule	      Explanation	                                         Example
            
            1	         Must start with a letter or underscore	                 name, _age
            2	         Cannot start with a number                            	 1name ❌
            3	         Can contain numbers after first character	             name1
            4	         Cannot contain spaces	                                 first name ❌
            5	         Can use underscore                                   	 first_name
            6	         Cannot use special symbols	                             name@ ❌
            7	         Case-sensitive                                     	 age and Age
            8	         Cannot use Python keywords                         	 if, class ❌
